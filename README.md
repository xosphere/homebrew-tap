# Xosphere Homebrew tap

```sh
brew install xosphere/tap/tokeniq
```

| Formula | What it installs |
|---|---|
| `tokeniq` | The TokenIQ CLI: query your AI economics data, author gateway configuration, issue virtual keys. |

Binaries come from Xosphere's public release bucket
(`https://xosphere-io-releases.s3.us-west-2.amazonaws.com/tokeniq/cli/<version>/`), each
pinned by its SHA-256 from the release's `checksums.txt`.

Upgrade with `brew upgrade tokeniq`.
